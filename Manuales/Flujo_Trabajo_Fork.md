# Manual de Contribución: Flujo de Trabajo con Fork y Git

Este documento detalla el procedimiento estándar para clonar, trabajar en características locales y enviar contribuciones al repositorio central del proyecto **KID-FIT** utilizando Visual Studio Code.

---

## 1. Configuración Inicial (Solo una vez)

### Paso 1: Realizar el Fork
1. Ve a la página principal del repositorio original de la organización en GitHub.
2. En la esquina superior derecha, haz clic en el botón **Fork**.
3. En el desplegable de la sección del **fork** entra en la opción **create a new fork**.
4. En el nombre del repositorio llamalo como **Kid_Fit-TUNombre**.

### Paso 2: Clonar tu Fork desde Visual Studio Code
1. Abre Visual Studio Code.
2. En las opciones sugeridas ingresa a la opción de clonar repositorio y selecciona el que diga **Kid_Fit-TuNombre**.
3. Clona tu repositorio personal:

```bash
git clone (https://github.com/TU_USUARIO/KID-FIT.git)
